YoRHa 戦術端末
『NieR:Automata』風のファンメイドのデスクトップ端末です。Square Enix とは関係ありません。インターフェースはすべてコードで描画しています。キャラクターは同梱のセット、または自分のフォルダーを選んだ場合はそのフォルダーから表示されます。
ハブが拠点です。各メニュー項目はサブメニューを持つ場所です。左上の「ハブ」で戻るか、マウスを動かさずにいると端末が自動で戻ります。
ハブと各場所を操作するには、Wallpaper Engine でマウス入力を許可する必要があります。メディア連携の情報は「情報」に表示されます。

YORHA HELPER // 注意事項
YoRHa Helper は、この壁紙の GitHub ページ（github.com/CalebFrums/yorha-terminal、helper フォルダ）で配布している小さな任意のプログラム。ダウンロードと起動は自分で行う。壁紙が何かをインストールすることはできない。
このスイッチがオンのとき、壁紙はこのPC内（127.0.0.1）でのみ Helper と通信し、用途は二つだけ：情報 で前の曲・再生/一時停止・次の曲を押したときに Windows のメディアキーを押すこと、そして「PCキーボードで入力」を選んだときに入力ボックスを開くこと。
プライバシー：インターネットや作者には何も送信されない。Helper はログを残さず、ファイルも書き込まず、読むのは自分の入力ボックスに打ち込まれた文字だけ。カレンダーとスケジュールはこのPCに残る。
スイッチがオフのとき、壁紙が Helper に接続することは一切ない。ここでいつでもオフに戻せる。
セットアップ手順は システム > YORHA HELPER にある。
