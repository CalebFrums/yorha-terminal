          YORHA HELPER // SETUP--CHECK AGAINSWITCH ON

          Optional. It adds working music buttons in INTEL and TYPE ON PC KEYBOARD in the calendar and schedule editors. Everything else works without it.

          1. 01On this PC, open github.com/CalebFrums/yorha-terminal in your web browser.
          2. 02Click Download YoRHaHelper.zip near the top of the page, then unzip it into a folder you will keep, such as Documents.
          3. 03In that folder, double-click Install-YoRHaHelper.cmd. If Windows asks, choose Run (or More info, then Run anyway). It starts now and with Windows.
          4. 04Come back here and press SWITCH ON. A disclaimer explains what it does first.
          5. 05Press PAIR, click the box that YoRHa Helper opens, then type the six-digit code shown here.
          6. 06The status above changes to ONLINE, and the music buttons in INTEL work.
          PAIRING CODE--- ---PAIR
          TO REMOVE IT: DOUBLE-CLICK UNINSTALL-YORHAHELPER.CMD, THEN DELETE THE FOLDER // IT ONLY TALKS TO THIS PC, KEEPS NO LOG AND NEVER GOES ONLINE
          YoRHa TACTICAL TERMINAL

          Fan-made desktop terminal in the style of NieR:Automata. Not affiliated with Square Enix. The interface is drawn in code. Characters come from the included set, or from your own folder once you choose one.

          The hub is home. Each menu entry is a place with its own sub-menu. Use HUB in the top left to come back, or leave the mouse alone and the terminal returns on its own.

          Mouse input must be allowed in Wallpaper Engine for the hub and the places to respond. Media integration feeds INTEL.

          GLORY TO MANKIND
          YORHA HELPER // DISCLAIMER

          YoRHa Helper is a small, optional program from this wallpaper's GitHub page (github.com/CalebFrums/yorha-terminal, folder helper). You download and start it yourself; the wallpaper cannot install anything.

          With this switch on, the wallpaper talks to it on this PC only (127.0.0.1) for two things: pressing the Windows media keys when you click previous, play/pause or next in INTEL, and opening a text box when you choose TYPE ON PC KEYBOARD.

          Privacy: nothing is sent to the internet or to the author. The helper keeps no log, and the only file it writes holds its pairing key. It reads only what you type into its own text box, and it obeys only a wallpaper you paired with it. Your calendar and schedule stay on this PC.

          With the switch off, the wallpaper never contacts the helper. You can switch it off again here at any time.

          Setup steps are in SYSTEM > YORHA HELPER.
